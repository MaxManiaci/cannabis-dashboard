# US Cannabis IB Dashboard

A static dashboard of US cannabis M&A, debt financing terms, state catalysts and news, for investment banking coverage.

- `index.html` — the page (tabs, tables, maps and charts; d3 in `assets/`)
- `data/*.json` — the data, one file per dataset, refreshed hourly from about 6am to 10pm ET
- `data/meta.json` — last refresh time; open pages re-check it every five minutes

Every row links to its public source (SEC filings, company releases, state regulators, trade press, Viridian Capital Advisors, CannaMonitor, AdvisorShares). Hemp is out of scope.

For information only; not investment advice.
